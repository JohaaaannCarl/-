反戒网校项目 - 使用教程

本教程教你从下载到运行的完整使用流程。

一、下载安装包

从 Releases 页面下载最新版本的安装包：
反戒网校项目.exe

文件大小约 50KB（不含离线包）或 180MB（含离线包）。

---

二、运行安装程序

1. 双击下载的 "反戒网校项目.exe"
（对了，卡巴斯基很爱吃）

注意：安装过程中会弹出一个 PowerShell 黑色窗口，显示下载和安装进度，请勿关闭。

---

三、等待环境配置

安装程序会自动完成以下操作：
- 检查并安装 Node.js（如未安装）
- 安装 Playwright 自动化框架
- 安装 Chromium 浏览器
- 生成启动脚本

耗时：3-10 分钟，取决于网络速度和电脑性能。

如果看到"安装完成！"提示，表示配置成功。

---

四、首次运行（必须登录抖音）

1. 安装完成后，桌面会出现"反戒网校项目"快捷方式
2. 双击快捷方式，会打开一个黑色命令行窗口和一个浏览器窗口
3. 浏览器会自动打开抖音网页版
4. 请手动登录你的抖音账号（扫码或手机号登录）
5. 登录成功后，关闭浏览器和命令行窗口
6. 下次运行时，登录状态会自动保持

注意：首次登录非常重要，不登录无法发表评论。

---

五、日常使用

1. 双击桌面"反戒网校项目"快捷方式
2. 等待浏览器打开并加载抖音推荐页
3. 程序会自动开始执行以下操作：
   - 点击评论区按钮
   - 输入预设评论内容
   - 按回车发送
   - 自动切换到下一个视频
4. 命令行窗口会显示当前进度，如"循环 15 / 1000"

---

六、停止程序

方式一：关闭浏览器窗口
直接点击浏览器右上角的 X，程序会自动停止。

方式二：在命令行窗口按 Ctrl + C
点击黑色命令行窗口，按键盘 Ctrl + C，然后按 Y 确认。

---

七、卸载程序

方式一：使用开始菜单卸载
点击开始菜单 → 反戒网校项目 → 卸载，按提示操作。

方式二：使用系统设置卸载
Windows 设置 → 应用 → 应用和功能 → 找到"反戒网校项目" → 卸载。

卸载时可选择是否同时删除：
- Node.js 运行时（约 100MB）
- Playwright 浏览器缓存（约 150MB）

---

八、常见问题

Q1: 安装时提示"环境配置失败，错误码: -196608"

原因：PowerShell 执行策略限制或网络问题。

解决：
1. 以管理员身份运行 PowerShell
2. 执行：Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
3. 按 Y 确认
4. 重新运行安装程序

Q2: 运行时提示"Cannot find module 'playwright'"

原因：环境未正确安装。

解决：重新运行安装程序，或手动在程序目录执行 npm install playwright@1.45.0

Q3: 浏览器打开了但没有自动评论

原因：
- 未登录抖音账号
- 抖音页面结构更新，导致程序找不到评论区按钮
- 网络加载慢，页面未完全加载

解决：
1. 确保已登录抖音
2. 等待页面完全加载后再观察
3. 如果长时间无反应，关闭后重新运行

Q4: 杀毒软件报毒

原因：安装程序包含 PowerShell 脚本和浏览器自动化行为，容易被误报。

解决：将程序添加到杀毒软件白名单，或暂时关闭杀毒软件后安装。

Q5: 评论发送失败或提示"发送太频繁"

原因：抖音反垃圾机制触发。

解决：
- 降低运行频率（修改 rpa.js 中的 randomDelay 参数）
- 减少单次运行时长
- 避免短时间内大量发送相同内容

---

九、重要注意事项

网络环境   - 首次安装需要下载约 200MB 数据，请确保网络畅通
   - 如果使用离线安装包，则无需联网



十、文件位置说明

安装后文件位置：
- 程序目录：C:\Users\你的用户名\AppData\Local\PlaywrightRPA
- 浏览器数据：C:\Users\你的用户名\AppData\Local\ms-playwright\douyin-profile
- Node.js：C:\Users\你的用户名\AppData\Local\NodeJS
- 快捷方式：桌面 和 开始菜单\反戒网校项目


如有其他问题，请在 Issues 中反馈
